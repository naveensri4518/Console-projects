# console-projects

A simple Java-based Bank Account Simulation System developed using OOPS concepts and MVC architecture.

## Features

- Create Account
- Deposit Money
- Withdraw Money
- Check Balance
- Display All Accounts

## Technologies Used

- Java
- OOPS
- MVC Architecture
- VS Code
