# Bank Management System using Java JDBC and MySQL

 -> Project Overview

This is a console-based Bank Management System developed using Java, JDBC, and MySQL. The project performs basic banking operations such as account creation, deposit, withdrawal, balance checking, account searching, and displaying all accounts with database connectivity.The project follows MVC (Model View Controller) architecture and demonstrates Java OOPS concepts along with JDBC database integration.

 🚀 Features

* Create Account
* Deposit Amount
* Withdraw Amount
* Search Account
* Check Balance
* Display All Accounts
* Delete account
* MySQL Database Connectivity
* JDBC Integration
* MVC Architecture

 🛠️ Technologies Used
